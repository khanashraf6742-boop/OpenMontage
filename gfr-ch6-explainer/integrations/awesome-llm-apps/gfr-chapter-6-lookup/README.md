# 📖 GFR Chapter 6 Lookup

Looks up any provision of **GFR 2017 Chapter 6** (Procurement of Goods and
Services, Rules 142–206) verbatim, with a plain Hinglish explanation — every rule,
sub-rule, clause, sub-clause, proviso, explanation, exception and amendment
footnote.

The point of the skill is narrow: **stop an agent from stating a threshold,
time limit, authority or penalty from memory.** It searches, it looks the rule up,
and it quotes what the corpus actually says.

![Nothing to demo — it is a lookup](https://img.shields.io/badge/runs-locally%20%26%20offline-1c7c46)

## Install

```bash
npx skills add https://github.com/khanashraf6742-boop/OpenMontage/tree/main/gfr-ch6-explainer/integrations/awesome-llm-apps/gfr-chapter-6-lookup
```

## Run

```bash
python3 scripts/gfr_lookup.py rules
python3 scripts/gfr_lookup.py rule 155
python3 scripts/gfr_lookup.py rule 172(1)
python3 scripts/gfr_lookup.py provisions --rule 173
python3 scripts/gfr_lookup.py search "purchase committee"
python3 scripts/gfr_lookup.py stats
```

Add `--json` (before or after the subcommand) for machine-readable output.

Python 3.9+ stdlib only. No network, no API key, no model call, and it never
writes to the corpus.

## Where the text comes from

`data/ch6.json` in the parent deliverable, generated by `node data/_json.js` from
`data/ch6-goods.js` and `data/ch6-services.js`. The verbatim layer is transcribed
from the official GFR 2017 compilation published by the Department of
Expenditure, Ministry of Finance, updated to 31.01.2026. The Hinglish layer is
hand-written.

If `data/ch6.json` is missing, the script says so and prints the command that
regenerates it.

## What it will not do

It cannot answer a question the corpus does not cover, and it does not try. If
the search returns nothing it says "no match" rather than guessing. Chapter 6 is
Rules 142–206 and nothing else — questions about CCS (Conduct) Rules, delegation
of financial powers, or works contracts belong elsewhere.

`search` is lexical, not semantic. It matches keywords present in the rule text,
so a conceptually phrased question ("how much can I buy without a tender") will
not find Rule 155 well. Use `provisions` without `--rule` to list the provision
titles and pick from those, or use an embedding-based retriever over `docs/`.
