ProvisionExam trap / granular point
Rule 142–143“Goods” includes software, technology transfer, licences, patents & incidental works (transport, insurance, installation, commissioning, training, maintenance); excludes books, publications, periodicals for a library.
Rule 144Fundamental principles: efficiency, economy, transparency, fair & equitable treatment, competition; Annual Procurement Plan on website; DoE may restrict bidders from countries sharing a land border (OM dt. 23.02.2023).
Rule 145 / 147Competent to incur expenditure = competent to sanction purchase (per Delegation of Financial Powers Rules). Items available on GeM must be bought on GeM. Rule 148 (Rate Contract) deleted vide OM dt. 02.04.2019.
Rule 149GeM ladder: ≤ ₹50,000 direct · > ₹50,000–₹10,00,000 L-1 among ≥ 3 manufacturers · > ₹10,00,000 mandatory online bidding / reverse auction. Automobiles: no ceiling. Demand must not be split (sub-rule viii).
Rule 150 / 151Registered suppliers: 1–3 years, list on website. Debarment: ≤ 3 years on conviction; ≤ 2 years for breach of code of integrity; reasonable opportunity to represent is must.
Rule 154Up to ₹50,000 without quotation + personal satisfaction certificate. [Scientific orgs: ₹2,00,000 — OM dt. 05.06.2025]
Rule 155Above ₹50,000 up to ₹5,00,000 via 3-member Local Purchase Committee + joint certificate. [Scientific orgs: ₹2,00,000–₹25,00,000]
Rule 157 / 149(viii)No splitting of demand to avoid higher sanction or GeM bidding.
Rule 158Five standard methods: Advertised Tender Enquiry, Limited Tender Enquiry, Two-Stage Bidding, Single Tender Enquiry, Electronic Reverse Auctions.
Rule 159 / 160E-publishing on CPPP mandatory (national-security exemption needs Secretary + FA concurrence, quarterly intimation to DoE; does not apply to Rules 154/155). All bids to be received through e-procurement portals.
Rule 161Advertised tender for estimated value ≥ ₹50 lakh; minimum 3 weeks (4 weeks if foreign bids); no GTE up to ₹200 crore without prior DoE-specified approval. [Scientific orgs: above ₹1 crore]
Rule 162Limited Tender Enquiry up to ₹50 lakh, more than three supplier firms; publish on GeM + GeM-CPPP; unsolicited bids not accepted; may exceed ₹50 lakh only in 3 certified situations. [Scientific orgs: up to ₹1 crore]
Rule 163 / 164 / 165Two-bid system (technical first, financial of technically acceptable only) · Two-stage bidding conditions (a)–(d) · Late bids never considered.
Rule 166Single Tender Enquiry only: sole manufacturer / emergency (record + competent authority approval) / standardisation (technical expert + competent authority). Proprietary Article Certificate needed for (i) & (iii).
Rule 167Electronic Reverse Auction allowed if detailed description feasible, competitive market, and monetary evaluation criteria.
Rule 170Bid Security 2–5% of estimated value; MSEs & DPIIT-recognised Startups exempt; valid 45 days beyond final bid validity; returned to unsuccessful bidders latest by 30th day after award.
Rule 171Performance Security 3–5% of contract value (goods/consultancy/non-consultancy services); valid 60 days beyond completion of all contractual obligations incl. warranty; bid security refunded on receipt of performance security.
Rule 172Advance payment ≤ 30% (private firm), ≤ 40% (Govt agency/PSU), maintenance contract ≤ 6 months’ value; bank guarantee safeguards.
Rule 173Transparency, competition, fairness; code of integrity; negotiation with bidders after bid opening severely restricted.
Rule 206Non-consulting services not covered by Rules 198–205 → refer to Rules 135–176 (goods procedure).
