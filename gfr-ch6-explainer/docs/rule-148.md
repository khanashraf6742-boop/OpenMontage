# Rule 148 — Rate Contract — DELETED

*Part A — Procurement of Goods · GFR 2017 Chapter 6*

## Verbatim text

Rule 148 (Rate Contract) stands deleted.

## Samajhne mein aasan (Hinglish)

Rule 148 (Rate Contract) delete ho chuka hai — DGS&D rate contracts ki baat ab is rule mein nahi hai.

## Exception

The entire Rule 148 has been deleted.

## Amendment footnote

Deleted vide DoE OM No. F.1/26/2018-PPD dated 02.04.2019.
