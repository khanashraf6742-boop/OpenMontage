## Interpretation note (Batch 10)

The request to cover "latest orders w.r.t. yearly submission of death certificate" was interpreted as the **annual Life Certificate / proof-of-life** requirement for Central Government pensioners (Jeevan Pramaan / Digital Life Certificate) — the only "yearly submission" regime in this space. The episode opens with this safa explicitly on frame.
